# 거래처 카톡 통합함 (Speciai-kakao-bot)

거래처 단톡방 대화가 개인 카톡에 섞여 묻히는 문제를 없애는 사내 콘솔.
업무 전용 안드로이드 단말의 봇이 **등록된 거래처 방만** 골라 서버로 보내고,
웹 콘솔에서 거래처별로 모아 본다.

## 핵심 — 개인 카톡은 서버에 오지 않는다

```
[업무 단말: 메신저봇R + bot/speciai-bot.js]
    ① 10분마다 GET /api/kakao/bot/rules 로 방 이름 규칙을 받아 단말에 보관
    ② 메시지 수신 → 방 이름이 규칙에 걸리는가?
         ├ 예   → POST /api/kakao/bot/ingest
         └ 아니오 → 전송하지 않음 (개인 카톡·가족방은 단말 밖으로 안 나감)
                      ↓ HTTPS
              [웹 콘솔 (Vercel)]
              거래처 매칭 · 멱등 저장 · 대시보드 표시
```

규칙을 한 번도 받지 못한 상태에서는 **아무것도 보내지 않는다**(fail-closed).

## 방 이름 규칙

우리 단톡방 이름은 `[삼성전자] 3분기 발주` 처럼 접두어 관행이 있다. 그 접두어를 등록한다.

| 거래처 | 규칙 | 방 이름 | 결과 |
|---|---|---|---|
| 삼성전자 | 접두어 `[삼성전자]` | `[삼성전자] 3분기 발주` | ✅ 수집 |
| 삼성전자 | 접두어 `[삼성전자]` | `[삼성전자] 납기 협의` | ✅ 같은 거래처로 |
| — | — | `고등학교 동창` | ⛔ 전송 안 함 |

방 이름 뒷부분이 바뀌어도 접두어가 같으면 계속 같은 거래처로 붙는다.
`완전일치` · `포함` · `정규식` 규칙도 쓸 수 있고, 겹치면 **더 구체적인(긴) 패턴이 이긴다**.

## 기능

| 영역 | 내용 |
|---|---|
| 수집 | 메신저봇R 온디바이스 봇 1경로. 사진 첨부 포함 |
| 필터 | 대시보드에 등록한 방 이름 규칙을 봇이 내려받아 단말에서 선차단 |
| 정리 | 거래처별 방 목록, 미처리/고정 필터, 방 색상, 처리완료 표시 |
| 진단 | 미분류 방 목록(이름·횟수만) — 규칙 누락을 눈으로 잡는다 |
| 시험 | 방 이름을 넣어 어느 거래처로 붙는지 등록 전에 확인 |

AI 기능은 없다. 매칭·멱등·집계는 전부 결정론이라 Anthropic API 키가 필요 없다.

## 요구사항

- Node.js 20 이상
- Supabase 프로젝트 (Postgres + Auth + Storage)
- 업무 전용 안드로이드 단말 1대 (메신저봇R 실행용)

## 시작하기

```bash
npm install
cp .env.example .env.local     # 최소 Supabase 3종 + KAKAO_INGEST_TOKEN
npm run dev                    # http://localhost:3000
```

DB 스키마는 `supabase/migrations/` 를 0001 → 0002 순서로 적용한다.

```bash
supabase db push
# 또는 Supabase 대시보드 SQL Editor 에 순서대로 붙여넣기
```

첫 로그인 후 워크스페이스를 만들고, 그 UUID 를 `KAKAO_WORKSPACE_ID` 에 넣는다.
(워크스페이스가 하나뿐이면 생략 가능 — 자동으로 그것을 쓴다.)

## 봇 셋업

`docs/봇_셋업가이드.md` 참고. 요약:

1. 업무 전용 단말에 메신저봇R 설치, 알림 접근·배터리 최적화 해제 허용
2. `bot/speciai-bot.js` 붙여넣고 상단 `ENDPOINT`·`RULES_ENDPOINT`·`TOKEN` 채우기
3. 컴파일 ON → 봇 계정으로 거래처 방 초대
4. 콘솔 "거래처" 탭에서 방 이름 접두어 등록

## 검증

```bash
npm run typecheck && npm test && npm run build
```

## 주의

- 각 거래처 방 참여자에게 자동 수집·저장 사실을 **사전 고지·동의**받아야 한다(개인정보보호법 §15).
- 카카오 이용약관상 자동화 도구는 계정 정지 리스크가 있다. 봇 계정은 업무 전용 계정으로 운용할 것.
  (이 봇은 카톡방에 말하지 않고 읽기만 하므로 리스크는 그만큼 낮다.)
- 단말 화면 꺼짐·앱 종료 시 수집이 멈춘다. 배터리 최적화 해제·상시 충전 권장.
